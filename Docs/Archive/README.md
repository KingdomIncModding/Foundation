# Historical Foundation Documentation

This folder preserves legacy Foundation 0.8–0.9 release notes, guides, migrations and engineering context. These documents are historical records and contain paths and commands that were valid for earlier source layouts.

**Do not run old root-level scripts named in archived documents.** The current entry point is `INSTALL-FOUNDATION.cmd`, with reusable scripts under `Tools/`. Use the project-root `README.md`, `Docs/Guides/`, `Docs/Core/` and `SDK/README.md` for current instructions.
