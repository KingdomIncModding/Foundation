# Foundation 0.10.6 — C# 14 build fix (2026-11-09)

## Reported Windows compiler errors

The user attempted to install the complete 0.10.6 Foundation source against the
actual Kingdom Inc assemblies. The build stopped at
`src/Foundation/Gameplay/GameItemsService.cs:23–25` with `CS9273` and `CS1061`,
plus two `CS9258` warnings, before packaging/installing a new binary.

## Root cause and fix

C# language version 14 adds contextual `field` support inside a property
accessor. The enhancement registry getter used `var field = ...`, so `field`
was resolved as the property's compiler-generated backing field rather than
as a `System.Reflection.FieldInfo`. Consequently `.GetValue(null)` was
incorrectly bound to `IReadOnlyDictionary<string, ItemEnhancement>` and
raised `CS1061`. The two reported compiler errors share one root cause.

The local variable was renamed to `enhancementRegistryField` (all three uses).
No API signature, game behavior, or persistence format changed. The registry
lookup still uses Harmony `AccessTools.Field` to access the game's existing
private static `ItemEnhancement._allEnhancements` dictionary. The attached
original game source confirms that declaration in
`Assets.Source.Items/ItemEnhancement.cs`.

The Stage A3–A7 source verifier now includes a guard against this regression.
The entire Foundation 0.10.6 source is repackaged—not an incremental patch.

## Verification boundary

The source-level Python tests and ZIP CRC check can be executed off-device.
**This environment does not provide the Windows/.NET Unity build dependencies
or a live Kingdom Inc runtime.** A successful Windows build/install and the
independent A1–A7 runtime suites are still required. No success claim is made
for those steps.

## Retry

Close the game, extract the corrected full ZIP into `KingdomInc\_Mods\`, then
run `Foundation\INSTALL-FOUNDATION.cmd` (or your existing install launcher).
This should eliminate the two *reported* compile errors; if the next build
reveals any additional errors, use the full compiler output for targeted fixes.
